# Complete Tailwind CSS Setup Guide for Django (Without NPM)

This guide shows you how to set up Tailwind CSS in a Django project using the **standalone Tailwind CLI binary** - no Node.js, npm, or package.json required!

## Prerequisites

- Django project (any version)
- Python virtual environment (recommended)
- Basic knowledge of Django templates and static files

## Step 1: Download the Tailwind CSS Standalone Binary

The Tailwind CSS standalone binary is a single executable file that includes everything you need to build Tailwind CSS without any dependencies.

### For Linux:

```bash
# Navigate to your Django project root
cd /path/to/your/django/project

# Download the latest Tailwind CSS standalone binary for Linux
curl -sLO https://github.com/tailwindlabs/tailwindcss/releases/latest/download/tailwindcss-linux-x64

# Rename it to 'tailwindcss'
mv tailwindcss-linux-x64 tailwindcss

# Make it executable
chmod +x tailwindcss
```

### For macOS (Intel):

```bash
curl -sLO https://github.com/tailwindlabs/tailwindcss/releases/latest/download/tailwindcss-macos-x64
mv tailwindcss-macos-x64 tailwindcss
chmod +x tailwindcss
```

### For macOS (Apple Silicon):

```bash
curl -sLO https://github.com/tailwindlabs/tailwindcss/releases/latest/download/tailwindcss-macos-arm64
mv tailwindcss-macos-arm64 tailwindcss
chmod +x tailwindcss
```

### For Windows:

```powershell
# Download using PowerShell
Invoke-WebRequest -Uri "https://github.com/tailwindlabs/tailwindcss/releases/latest/download/tailwindcss-windows-x64.exe" -OutFile "tailwindcss.exe"
```

**Verify the installation:**

```bash
./tailwindcss --help
```

You should see output showing the Tailwind CSS version and available commands.

## Step 2: Create Your Input CSS File

Create a `static` directory in your Django project root if it doesn't exist, then create a `css` subdirectory:

```bash
mkdir -p static/css
```

Create an **input.css** file at `static/css/input.css`:

```css
@import "tailwindcss";

/* Add your custom styles below */

/* Example: Custom blockquote styling */
.prose blockquote {
    position: relative;
    background: linear-gradient(135deg, #f8fafc 0%, #f1f5f9 100%);
    border-left: 4px solid #3b82f6;
    padding: 1.5rem 2rem;
    margin: 2rem 0;
    border-radius: 8px;
    box-shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.1), 0 2px 4px -1px rgba(0, 0, 0, 0.06);
    font-style: normal;
    color: #475569;
}

.prose blockquote p {
    margin: 0;
    font-size: 1.1rem;
    line-height: 1.7;
}

/* Dark mode support */
@media (prefers-color-scheme: dark) {
    .prose blockquote {
        background: linear-gradient(135deg, #1e293b 0%, #334155 100%);
        color: #cbd5e1;
        border-left-color: #60a5fa;
    }
}
```

**Note:** Tailwind CSS v4+ uses the new `@import "tailwindcss"` syntax instead of the old `@tailwind` directives.

## Step 3: Configure Django Static Files

Ensure your Django settings (`settings.py`) are configured for static files:

```python
from pathlib import Path

BASE_DIR = Path(__file__).resolve().parent.parent

# Static files (CSS, JavaScript, Images)
STATIC_URL = '/staticfiles/'
STATIC_ROOT = BASE_DIR / 'staticfiles'
STATICFILES_DIRS = []

# Add static directory if it exists
_static_dir = BASE_DIR / "static"
if _static_dir.exists():
    STATICFILES_DIRS.append(_static_dir)
```

**Your directory structure should look like this:**

```
your-django-project/
├── manage.py
├── tailwindcss              # Standalone binary
├── static/
│   └── css/
│       ├── input.css        # Your input file
│       └── output.css       # Generated by Tailwind (will be created)
├── staticfiles/             # Collected static files (production)
├── templates/
│   └── base.html
├── your_app/
│   ├── models.py
│   ├── views.py
│   └── ...
└── your_project/
    ├── settings.py
    ├── urls.py
    └── wsgi.py
```

## Step 4: Generate Your CSS

Now you'll use the Tailwind CSS binary to process your input CSS and generate the final output CSS.

### One-time Build (for production):

```bash
./tailwindcss -i ./static/css/input.css -o ./static/css/output.css --minify
```

### Watch Mode (for development):

This will automatically rebuild your CSS whenever you make changes:

```bash
./tailwindcss -i ./static/css/input.css -o ./static/css/output.css --watch
```

**What happens:**
- Tailwind scans your HTML/Django template files for class names
- It generates only the CSS you're actually using
- The output is written to `static/css/output.css`

**Tip:** Keep the watch command running in a separate terminal while developing!

## Step 5: Include CSS in Your Templates

Update your base template (`templates/base.html`) to include the generated CSS:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>{% block title %}My Django App{% endblock %}</title>
    
    {% load static %}
    <link rel="stylesheet" href="{% static 'css/output.css' %}">
    
    {% block extra_head %}{% endblock %}
</head>
<body class="bg-white min-h-screen flex flex-col">
    <main class="flex-grow">
        {% block content %}{% endblock %}
    </main>
    
    {% block extra_js %}{% endblock %}
</body>
</html>
```

Now you can use Tailwind CSS classes in your Django templates:

```html
{% extends 'base.html' %}

{% block content %}
<div class="container mx-auto px-4 py-8">
    <h1 class="text-4xl font-bold text-gray-900 mb-4">
        Welcome to My Django App
    </h1>
    <p class="text-lg text-gray-600">
        This is styled with Tailwind CSS!
    </p>
    <button class="mt-4 bg-blue-500 hover:bg-blue-700 text-white font-bold py-2 px-4 rounded">
        Click Me
    </button>
</div>
{% endblock %}
```

## Step 7: Development Workflow

### Daily Development Process:

1. **Start your Django development server** (Terminal 1):
   ```bash
   source .venv/bin/activate  # Activate virtual environment
   python manage.py runserver
   ```

2. **Start Tailwind watch mode** (Terminal 2):
   ```bash
   ./tailwindcss -i ./static/css/input.css -o ./static/css/output.css --watch
   ```

3. **Make changes to your templates or input.css**
   - Tailwind automatically rebuilds when it detects changes
   - Refresh your browser to see the changes

### Adding Custom Styles:

Add custom CSS to `static/css/input.css` below the `@import "tailwindcss"` line:

```css
@import "tailwindcss";

/* Custom component styles */
.btn-primary {
    @apply bg-blue-500 hover:bg-blue-700 text-white font-bold py-2 px-4 rounded;
}

.card {
    @apply bg-white shadow-lg rounded-lg p-6;
}
```

## Step 8: Production Deployment

### Before Deploying:

1. **Build optimized CSS:**
   ```bash
   ./tailwindcss -i ./static/css/input.css -o ./static/css/output.css --minify
   ```

2. **Collect static files:**
   ```bash
   python manage.py collectstatic --noproxy
   ```

3. **Commit your changes:**
   ```bash
   git add static/css/output.css
   git commit -m "Update Tailwind CSS build"
   ```

### On Your Production Server:

You have two options:

**Option 1: Pre-built CSS (Recommended)**
- Just deploy your code with the committed `output.css`
- No need to install the Tailwind binary on the server
- Simpler and faster deployment

**Option 2: Build on Server**
- Download the Tailwind binary on your server
- Run the build command during deployment
- Useful if you have dynamic content that affects CSS

### Environment Variables:

In production, make sure your `settings.py` has:

```python
DEBUG = False
ALLOWED_HOSTS = ['yourdomain.com', 'www.yourdomain.com']
STATIC_ROOT = BASE_DIR / 'staticfiles'
```

## Troubleshooting

### Issue: Styles not appearing

**Solutions:**
1. Check that `output.css` was generated:
   ```bash
   ls -lh static/css/output.css
   ```

2. Verify the CSS is being loaded in your browser's developer tools (Network tab)

3. Make sure `STATICFILES_DIRS` includes your `static` directory in `settings.py`

4. Clear browser cache or do a hard refresh (Ctrl+Shift+R or Cmd+Shift+R)

### Issue: Permission denied when running tailwindcss

**Solution:**
```bash
chmod +x tailwindcss
```

### Issue: Tailwind not detecting template changes

**Solutions:**
1. Make sure watch mode is running:
   ```bash
   ./tailwindcss -i ./static/css/input.css -o ./static/css/output.css --watch
   ```

2. Tailwind automatically scans `.html`, `.js`, and common template files
   - If using custom extensions, you'll need a config file (see advanced section below)

### Issue: output.css is too large

**Solutions:**
1. Always use `--minify` for production builds
   ```bash
   ./tailwindcss -i ./static/css/input.css -o ./static/css/output.css --minify
   ```

2. Check that you're not importing unnecessary custom CSS

3. The standalone binary automatically purges unused styles by scanning your templates

## Advanced Configuration (Optional)

Tailwind v4 works without a config file by default, but you can customize it by adding CSS variables in your `input.css`:

```css
@import "tailwindcss";

/* Custom theme configuration */
@theme {
  --color-primary: #3b82f6;
  --color-secondary: #8b5cf6;
  --font-sans: 'Inter', system-ui, sans-serif;
  
  --breakpoint-3xl: 1920px;
}

/* Your custom styles */
.btn-custom {
  background: var(--color-primary);
  color: white;
  padding: 0.5rem 1rem;
  border-radius: 0.375rem;
}
```
